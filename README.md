# PromptLab

An AI-powered prompt improvement tool built with React + Vite, using the Google Gemini 2.0 Flash API (free).

## Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Add your Gemini API key (optional)
Get a free key at https://aistudio.google.com/apikey

You can either:
- Copy `.env.example` to `.env` and set `VITE_GEMINI_API_KEY=your_key`
- Or enter it directly in the app UI when prompted

### 3. Run the dev server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```

## Features
- Instant prompt quality score (0–100)
- 5-category breakdown: Clarity, Specificity, Context, Structure, Constraints
- AI-enhanced prompt rewrite
- Suggested improvement actions
- Powered by Gemini 2.0 Flash (free tier)
